# RuneWorld

Сайт сообщества Minecraft-сервера RuneWorld. Проект представляет собой статический двуязычный сайт с русской и украинской версиями.

[Открыть сайт](https://kristoferua.github.io/rune-world-main.github.io/)

## Возможности

- главная страница с информацией о сервере;
- страницы сезонов, событий и кланов;
- список игроков с краткими профилями;
- русская и украинская локализации;
- адаптивная навигация для компьютеров и мобильных устройств;
- публикация через GitHub Pages.

## Технологии

Сайт работает без сборщика и серверной части. В проекте используются HTML, CSS и JavaScript.

## Структура проекта

```text
.
├── index.html          # главная страница на русском языке
├── pages/
│   ├── ru/             # русскоязычные страницы
│   ├── uk/             # украиноязычные страницы
│   └── dev/            # тестовые страницы
├── assets/
│   ├── css/            # стили
│   ├── js/             # клиентские скрипты
│   └── images/         # изображения и иконки
├── docs/               # дополнительные материалы
└── .github/            # настройки и шаблоны GitHub
```


## Локальный запуск

Для просмотра можно открыть `index.html` напрямую в браузере. Если браузер ограничивает загрузку локальных ресурсов, запустите из корня проекта простой HTTP-сервер:

```powershell
py -m http.server 8000
```

После этого откройте `http://localhost:8000`.
